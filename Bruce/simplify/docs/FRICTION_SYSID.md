# 摩擦标定现场操作手册（吊装式）

> 目标：把真机吊起来，跑 **Example54** 辨识 12 个腿关节的摩擦参数 `[b 粘性, fc 库仑]`，
> 离线回归后填回 `rl_controller.cpp` 的 `LEG_FF_FC[12]/LEG_FF_FV[12]` 做摩擦前馈。
>
> 本文档以**终端输出**为索引：看到每一行输出 → 判断正常/异常 → 该怎么做。

---

## 1. 原理与文件（30 秒速览）

- **原理（重力抵消法）**：同一关节角 θ 下，正反向恒速扫掠的电机扭矩差，重力项被消去：
  `τ(+v) − τ(−v) = 2b·v + 2fc`。恒速由「阻抗位置斜坡 + 重力前馈 tau_ff=g_est」实现
  （**不用 SPEED 速度模式**——关节电机高减速比、速度环无位置保护，危险）。
- **为什么先标重力**：腿自重重力矩 8~12 Nm，比摩擦 0.2~0.5 Nm 大一个数量级。纯 PD 位置斜坡
  追不上恒速（扭矩全被重力吃掉），必须先位置保持标出 `g_est(θ)` 做前馈。
- **相关文件**：
  - `src/app/examples/ex_diag.cpp` —— Example54_FrictionSysId（采集）
  - `tool/friction_id_offline.py` —— 离线回归（`b/fc ± σ`）
  - `src/app/main.cpp` —— 当前激活 Example54
  - 数据落盘目录：`log/fric_id/`
- **预计耗时**：12 关节 × ~5 分钟 ≈ **60~70 分钟**（一次吊起做完）。

---

## 2. 准备：挂狗与上电

### 2.1 挂狗（硬指标，做不好数据全废）
- base 用**支撑架/多吊点刚性固定**，4 腿全部悬空、不触地、腿间不碰。
- 狗动腿时 **base 晃动 < ~1°**。晃了 → 重力方向漂移 → 同 θ 配对失效 → 回归全错。
- 腿自然垂下，确保扫掠区间（±0.35~0.5 rad）内不碰吊具/支撑架。

### 2.2 上电
1. 上电，**先不使能**，手动确认 4 腿能自由摆动、无卡滞。
2. 运行程序：`bin/can_motor_app`（main.cpp 已激活 Example54）。
3. **准备好随时 Ctrl+C**（现在已是优雅急停：失能后退出）。

## 3. 运行 Example54 —— 终端输出逐条解读

### 3.1 启动阶段

```
========== 示例 54：吊装摩擦辨识 ==========
[WARN] 狗必须吊起悬空、base 刚性固定、腿悬空不触地！
[INFO] 逐关节：重力标定(20点×4遍) → 前馈恒速扫掠(3档×5圈×4回合)，落盘 log/fric_id/
[INFO] 12 关节约 50~70 分钟；异常立即 Ctrl+C 失能。
```

- **看到 `[ERROR] 初始化失败`**：USB2CAN 初始化失败。
  → 检查 USB 是否插入、`ls /dev/ttyACM0` 是否存在、是否被别的进程占用，重插后重跑。

### 3.2 使能后姿态确认（每关节一条）

```
[INFO] CAN0-M1(hip): θ_c=+0.02 amp=0.35 (限位[-1.05,0.00])
[INFO] CAN0-M2(thigh): θ_c=-0.88 amp=0.50 (限位[-1.22,1.57])
[INFO] CAN0-M3(calf): θ_c=+1.85 amp=0.45 (限位[1.05,3.14])
...
```

| 输出 | 含义 | 正常标准 | 异常处理 |
|------|------|---------|---------|
| `θ_c=+0.02 amp=0.35` | 该关节扫掠中心（吊起后当前角）与半幅 | θ_c 在限位内、amp≈设定的 0.35/0.50/0.45 | 见下 |
| `[WARN] ...贴近限位，半幅压到 0.12` | 吊起后该关节卡在限位附近，扫掠区间被压小 | 少数关节可接受（该关节数据覆盖小） | 若 **hip** 也压到 0.12（说明腿没垂到中间），**重新挂狗**让腿自然下垂再跑 |
| 4 条腿同关节 θ_c 差异大 | 吊起姿态左右不对称 | 可接受（配对不依赖对称） | —— |

**这条输出是"第一道体检"**：12 条都合理才继续。若 amp 普遍被压小 → 吊姿有问题，先重新挂。

### 3.3 逐关节：移动扫掠中心

```
===== [1/12] CAN0-M1(hip) θ_c=+0.02 amp=0.35 =====
[INFO] 移到 θ_c（+0.02）完成
```

- `[WARN] 移到 θ_c 偏差 0.083 rad（将靠重力标定拉回）`：移动慢或重力拉偏。
  → 正常，重力标定第一步会把它拉到位。偏差 >0.15 才需警惕（机械卡滞）。

### 3.4 阶段 C：重力标定（每关节 ~2 分钟，输出 4 行进度）

```
  重力标定第 1/4 遍完成
  重力标定第 2/4 遍完成
  重力标定第 3/4 遍完成
  重力标定第 4/4 遍完成
[阶段C] 重力标定完成：θ∈[-0.33,+0.37], g∈[+6.4,+15.0] Nm (Δg=8.6)
```

**这条输出是"第二道体检"，盯紧 `g∈[...]` 量级**：

| 关节 | 量级参考（sim 实测） | 判定 |
|------|--------------------|------|
| hip | +6 ~ +15 Nm（Δg 8~9） | g≈0 或 Δg<1 → **电机没动/标定失败** |
| thigh | -1 ~ +11 Nm（Δg 12） | 同上 |
| calf | -11 ~ -5 Nm（Δg 6） | 同上 |

- **`g` 数值合理** → 继续，重力前馈数据就绪。
- **`g` 全 ≈ 0 或 Δg < 1 Nm** → 该关节标定时位置没变（PD 跟不上 or 指令没到）。
  → Ctrl+C 失能，检查该电机：方向位是否反、kp 是否够、机械是否卡死。
- **`g` 数值异常大（>50 Nm）** → 扭矩反馈解析错（量程/方向），排查反馈链路，别继续。

### 3.5 阶段 D：前馈恒速扫掠（每关节 ~3 分钟，输出 12 行）

```
  回合1 档v=0.3 完成（11650 样本）
  回合1 档v=0.5 完成（7000 样本）
  回合1 档v=0.8 完成（4375 样本）
  回合1 落盘 → log/fric_id/C0M1_R0.csv
  回合2 档v=0.3 完成（11580 样本）...
  ...
```

**样本数是最直接的"第三道体检"**：

| 档位 | 单程时长 (hip amp=0.35) | 预期样本/回合 |
|------|------------------------|--------------|
| v=0.3 | 2.33s | ~11000+ |
| v=0.5 | 1.4s | ~7000 |
| v=0.8 | 0.875s | ~4300 |

- 样本数接近上表 → 正常（样本数 × 500Hz ≈ 单程时长 × 圈数，对得上就是真在扫掠）。
- **样本数异常少或 0** → 该档没跑起来（速度没跟上 or 立即 aborted）。
  → Ctrl+C 查：扫掠是否在动、前馈 g_est 是否生效（`g∈` 合理则生效）。
- **听到异响 / 看到腿部剧烈抖动** → **立即 Ctrl+C**（急停失能）。

### 3.6 关节完成与整体完成

```
===== CAN0-M1(hip) 完成 =====
...
[INFO] Example54 完成：12 关节完成，0 失败。
[INFO] 数据 → log/fric_id/，离线回归：python tool/friction_id_offline.py
```

- `12 关节完成，0 失败` → 全部成功，进入离线回归。
- `N 关节完成，M 失败` → 有 ABORT。看是哪个关节，确认原因后：可重跑该关节
  （脚本会覆盖同名 CSV，其余关节数据保留，无需重跑全部）。

### 3.7 ABORT / 急停（看屏幕，随时准备）

```
[ABORT] 位置误差超限或用户急停（Ctrl+C），失能退出
[INFO] 用户急停，已失能。已完成的关节数据保留在 log/fric_id/。
```

| 触发 | 含义 | 处理 |
|------|------|------|
| 位置误差超限（>0.2 rad） | 关节没跟上指令（PD 扛不住 or 机械卡住 or 撞吊具） | 检查该关节机械/吊姿，重跑该关节 |
| Ctrl+C | 人为急停 | 已完成关节数据保留，可继续离线回归 |

**急停后**：程序自动失能全部电机并退出，安全。数据不丢。

## 4. 离线回归

### 4.1 运行

```bash
python tool/friction_id_offline.py
# 或自测管线（不读真机数据，生成模拟数据验证脚本）：
python tool/friction_id_offline.py --demo
```

### 4.2 输出解读

```
 关节       θ_c     amp      b±σ               fc±σ              R²    质量
----------------------------------------------------------------------
 C0M1      0.02    0.35   0.5013±0.0012   0.1998±0.0009    0.999  OK
 C0M2     -0.88    0.50   0.5500±0.0015   0.2500±0.0011    0.998  OK
 ...
```

| 列 | 含义 | 质量判定 |
|----|------|---------|
| `b±σ` | 粘性摩擦 (Nm·s/rad)，4 回合均值±标准差 | **σ/均值 < 30%** 且 b > 0 |
| `fc±σ` | 库仑摩擦 (Nm)，同上 | **σ/均值 < 30%** 且 fc > 0 |
| `R²` | τ_diff 相对 2b·v+2fc 的线性拟合度 | **> 0.7** |
| 质量 | OK / ⚠ | 全部满足才算 OK |

- **全部 OK** → 结果可信，填回（§5）。
- **部分 ⚠**（σ 大 / R² 低）→ 该关节数据质量差，常见原因与对策：
  - 扭矩反馈噪声大 → 重跑时把 `ROUNDS` 调大（4→6）或 `CYC_PER_VEL` 调大（5→8）。
  - 扫掠没跟上恒速（|ω| 离 v 远）→ 配对用实际 |ω| 回归，b 仍准，但 fc 受噪声影响 → 多圈平均。
  - R² 低 + 重力标定 Δg 小 → 重力标定失败（回 §3.4 检查）。
- **`[ERROR] 未找到 log/fric_id/C*M*_info.txt`** → 没跑过 Example54 或数据被删，先跑采集。

### 4.3 参考量级（判断结果是否合理）

| 参数 | 参考（sim 注入 / 课程） | 异常值 |
|------|------------------------|--------|
| b（粘性） | 0.3 ~ 0.6 | b=0（无阻尼？）或 b>2（异常大） |
| fc（库仑） | 0.2 ~ 0.3 | fc=0（无静摩擦？）或 fc>1（异常大） |

## 5. 结果填回

把回归出的 `b±σ`、`fc±σ` 填入 `src/strategy/rl_controller.cpp` 的数组（**顺序一致**：
CSV 是 CAN 顺序 per-leg hip/thigh/calf = POLICY 顺序 FL_hip,FL_thigh,FL_calf,FR_hip,...）：

```cpp
const float LEG_FF_FC[12] = { /* 填 fc 均值 */ };
const float LEG_FF_FV[12] = { /* 填 b 均值 */ };
```

填回后**必须做一次整狗验证**（不是直接跑 RL）：
1. 吊起 → 加前馈做同一低速斜坡，对比纯 PD 的跟踪误差（RMS 应降 ≥30%）。
2. 落地站立 → 观察是否有越动越快/振荡（前馈过大）。异常 → 关闭 `LEG_FF_ENABLE` 复核。

## 6. 常见问题排查表

| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 启动 `[ERROR] 初始化失败` | USB2CAN 没插/被占用 | 查 `/dev/ttyACM0`，重插重跑 |
| amp 普遍被压到 0.12 | 吊姿不对，腿卡限位 | 重新挂狗，让腿自然下垂 |
| 重力标定 g≈0 | 电机没动 | 查方向位/使能/kp/机械 |
| 重力标定 Δg<1 | 标定期间位置没扫 | 同上 |
| 扫掠样本数 0 | 该档没跑起来 | Ctrl+C，查扫掠是否在动 |
| 扫掠剧烈抖动/异响 | 前馈方向反/增益过大 | **立即 Ctrl+C**，查 g_est 符号 |
| 离线回归 σ 大 | 噪声大 | ROUNDS/CYC_PER_VEL 调大重跑该关节 |
| 离线回归 R² 低 | 恒速没跟上/标定差 | 检查 g 量级 + 扫掠样本数 |
| 某关节数据要重跑 | ABORT 或质量差 | 删掉该关节旧 CSV，重跑只跑该关节 |

## 7. 参数速查（ex_diag.cpp Example54 宏区，改一处重编译）

| 参数 | 默认 | 什么时候调 |
|------|------|-----------|
| `SWEEP_AMP[3]` | 0.35/0.50/0.45 | 扫掠区间（限位内自适应，一般不动） |
| `VEL_STEPS[3]` | 0.3/0.5/0.8 | 关节量程 3 rad/s 的 10~27%，别加太快 |
| `CYC_PER_VEL` | 5 | σ 大/噪声大 → 调大（8） |
| `ROUNDS` | 4 | 误差带要求更严 → 调大（6），时间 +50% |
| `GRID_PTS` | 20 | 重力曲线更密 → 调大 |
| `GRID_ROUNDS` | 4 | 重力标定更准 → 调大 |
| `GRAV_HOLD_S` | 1.5 | 每点保持时长，静摩擦大 → 调大 |
| `LOCK_KP/KD`、`SWEEP_KP/KD` | 500/50 | 腿抖/跟不上 → 试调 |
| `POS_ERR_LIMIT` | 0.20 | 位置保护阈值 |
| `MIN_AMP` | 0.12 | 最小扫掠半幅 |

**时间预算**：`ROUNDS=4` 约 60-70 分钟；调大到 6 → 约 90 分钟。
