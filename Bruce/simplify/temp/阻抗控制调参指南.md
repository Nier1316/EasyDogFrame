# 四足狗起立调参指南

> 针对现象：狗站不起来，但关节扭矩离限幅还很远（实测占比约 25%）。
> 结论：**不是电机没劲，是阻抗模式下没给前馈扭矩，支撑力全靠位置误差换。**

---

## 一、为什么扭矩上不去

阻抗模式的扭矩不是直接下发的，是电机固件按下式算出来的：

```
τ = kp · (θ_target − θ_actual) + kd · (ω_target − ω_actual) + τ_ff
```

当前代码 `src/example.cpp:1735`：

```cpp
motor_mgr.SendImpedance(leg, j + 1, pos, 0.0f, KP, KD, 0.0f);
//                                                    ^^^^ τ_ff = 0
```

前馈项是 0，所以**全部支撑力矩必须由位置误差换来**。

以 `kp = 150 N·m/rad` 为例：

| 需要的保持扭矩 | 必需的位置误差 | 折算角度 |
|---|---|---|
| 10 N·m | 0.067 rad | 3.8° |
| 30 N·m | 0.200 rad | 11.5° |
| 60 N·m | 0.400 rad | 22.9° |

要出 30 N·m，腿必须先塌 11.5°。而塌下去狗就站不起来——**这是死循环**。
"扭矩离限幅远" 是结果不是原因：误差小 → 扭矩小，不是电机能力不足。

### 实测验证

用 `torque / err` 反推固件实际生效的 kp（数据取自 `log/recv_20260804_140101.csv`
与同名 `send_` 日志，稳态窗口 15–20 s）：

| CAN-电机 | err (rad) | torque (N·m) | 下发 kp | 反推 kp |
|---|---|---|---|---|
| 0-1 Hip | −0.0476 | −7.28 | 150 | 153.0 |
| 2-3 Calf | −0.1441 | −21.75 | 150 | 150.9 |
| 3-2 Thigh | 0.1909 | 28.45 | 150 | 149.0 |
| 3-3 Calf | 0.1968 | 29.35 | 150 | 149.1 |

反推值 121–161，与下发 150 吻合 → **阻抗环工作正常，kp 没有被量程换算削掉。**
问题确实只在前馈缺失。

> 注：上述扭矩是四腿挂在架上、机身未水平时测得，**不代表真实站立载荷**。
> 落地后需重测，见第三步。

## 二、调参顺序

严格按顺序做。跳步会把问题叠在一起，看不出是哪一项起的作用。

### 第 0 步（前置）：确认固件量程

**这一步不做，后面抬 kp/kd 有振荡风险。**

项目 `include/motor_drive/ele_motor_def.h:107` 用的量程：

```c
kp_max = 500,  kd_max = 500,  ki_max = 500
```

厂商参考实现 `tool/motor_rw_api.c` 用的是 `KD_MAX = 100`、`KI_MAX = 10000`。
两者不一致。若固件按 100 解码 kd，则**下发 kd=20 实际只生效 4**，
抬完 kp 必然振荡，且原因很难从现象上看出来。

读固件真实量程：

```cpp
float2bag(motor, 0.0f, 0, MOTOR_WR_CAN_REPLY_MAX_KP);      // 0x61
float2bag(motor, 0.0f, 0, MOTOR_WR_CAN_REPLY_MAX_KD);      // 0x62
float2bag(motor, 0.0f, 0, MOTOR_WR_CAN_REPLY_MAX_Torque);  // 0x60
```

`RW` 参数置 0 表示读。**注意**：这三个回帧当前会掉进
`src/motor_drive/ele_motor.cpp:244` 的 `default: break;` 被静默丢弃，
必须先补一条打印才看得到：

```cpp
default:
    printf("[PARAM] CAN%d motor%d type=0x%02X value=%f\n",
           motor.device_idx, motor.motor_id, type, canRecev.fValue);
    break;
```

**验收**：读回的 kp_max / kd_max / t_max 与 `MOTOR_LIMITS` 表逐项一致。
不一致就改 `MOTOR_LIMITS` 去对齐固件，**不要改固件**。

### 第 1 步：加重力前馈（根治下垂）

把静态保持力矩直接给进去，位置误差就不必再承担支撑作用。

```cpp
// 各关节静态保持力矩，索引 [leg][joint]
// 初值用实测稳态扭矩填，落地后重测
static const float tau_ff[4][3] = {
    /* CAN0 左前 */ {  0.0f,  -8.0f,   8.0f },
    /* CAN1 右前 */ {  0.0f,  -8.0f,   8.0f },
    /* CAN2 左后 */ {  0.0f, -16.0f,  16.0f },
    /* CAN3 右后 */ {  0.0f, -16.0f,  16.0f },
};

motor_mgr.SendImpedance(leg, j + 1, pos, 0.0f, KP, KD, tau_ff[leg][j]);
```

**取值方法**：让狗以现有参数尽力站住（哪怕塌着），跑绘图工具读稳态扭矩：

```bash
conda activate dog
python tool/plot_motor_torque.py
```

统计表里的 `mean` 列就是该关节的稳态保持扭矩，直接填进 `tau_ff`。

**符号必须与实测同号**。填反了前馈会和重力同向，腿会被主动压下去。
第一次填建议只给实测值的 50%，确认方向正确再补足。

**验收**：同一目标姿态下，位置误差应显著减小（30 N·m 那档从 0.20 rad
降到 0.05 rad 以内），而扭矩基本不变。误差没降说明前馈没生效或符号反了。

### 第 2 步：抬 kp/kd

前馈到位后如果仍有残余下垂，再动增益。`src/example.cpp:1616`：

```cpp
const float KP = 150.0f;    // → 300 ~ 400
const float KD = 20.0f;     // 随 kp 一起抬
```

kp 加倍必须同步抬 kd，否则振荡。工程做法是 **kp 每翻倍、kd 乘 1.4**
（对应临界阻尼附近 `kd ≈ 2ζ√(kp·J)`）：

| kp | kd |
|---|---|
| 150 | 20 |
| 200 | 23 |
| 300 | 28 |
| 400 | 33 |

**一次只加 50，加完观察有无抖动再继续。** 上限受第 0 步读回的量程约束。

**验收**：站立时目视无高频抖动，听不到关节啸叫；
`--psd` 频谱图上没有新增的窄峰。

```bash
python tool/plot_motor_torque.py --psd
```

### 第 3 步：落地重测前馈

前两步都在挂架上做。落地后载荷分布变化很大，必须重跑第 1 步的取值流程，
用真实站立载荷更新 `tau_ff`。

## 三、诊断工具

```bash
conda activate dog

python tool/plot_motor_torque.py                  # 最新日志，4 电机分图
python tool/plot_motor_torque.py --field raw      # 标定前原始值
python tool/plot_motor_torque.py --port 3         # 只看某路 CAN
python tool/plot_motor_torque.py --window 8.9 9.1 # 放大某段时间(秒)
python tool/plot_motor_torque.py --psd            # 追加功率谱，查振荡
```

输出到日志同目录：矢量 PDF + 300 dpi PNG + 统计量 CSV。
统计表关键列：

- `mean` — 稳态保持扭矩，**填 `tau_ff` 就看这列**
- `rms` — 持续热负荷，长时间站立看这个而不是 `max`
- `p99_abs` — 比 `max` 抗单点毛刺
- `util_pct` — 占限幅百分比，>90% 会单独告警

反推固件实际 kp（确认阻抗环是否正常）：

```bash
cd log
awk -F, -v T0=15000 -v T1=20000 '
FILENAME==ARGV[1] && FNR>1 && $1>=T0 && $1<=T1 {k=$2"-"$3; sp[k]+=$6; skp[k]+=$8; sn[k]++}
FILENAME==ARGV[2] && FNR>1 && $1>=T0 && $1<=T1 {k=$2"-"$3; rp[k]+=$4; rt[k]+=$6; rn[k]++}
END{ for(k in sn) if(rn[k]>0){ e=sp[k]/sn[k]-rp[k]/rn[k]; tq=rt[k]/rn[k];
  printf "%-7s err=%8.4f  tq=%7.2f  cmd_kp=%6.1f  imp_kp=%7.1f\n",
         k, e, tq, skp[k]/sn[k], (e!=0?tq/e:0)} }' \
  send_YYYYMMDD_HHMMSS.csv recv_YYYYMMDD_HHMMSS.csv | sort
```

`imp_kp` 应接近 `cmd_kp`。偏差大于 2 倍说明量程不匹配，回第 0 步。

## 四、参数速查

| 参数 | 位置 | 当前值 | 建议 |
|---|---|---|---|
| `KP` | `src/example.cpp:1616` | 150 | 前馈到位后再提到 300–400 |
| `KD` | `src/example.cpp:1617` | 20 | 随 kp 乘 1.4/倍 |
| `τ_ff` | `src/example.cpp:1735` 第 7 参 | 0 | **优先改**，填实测稳态扭矩 |
| 站立指令角 | `src/example.cpp:1667` | Hip 0° / Thigh −30° / Calf 60° | 暂不动 |

## 五、安全

- **每次上电前狗必须在架上，手放在断电开关旁。**
- 第 2 步抬 kp 风险最高：若第 0 步跳过、固件 kd 量程实际是 100，
  起立瞬间会剧烈振荡。
- 前馈符号填反会让腿主动下压，第一次给 50% 幅值验证方向。
- 落地测试前先在架上完整走一遍第 1、2 步。
