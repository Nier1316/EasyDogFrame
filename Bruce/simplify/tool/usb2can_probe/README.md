# 达妙 USB2CAN 探针工具

独立小工具，通过 `/dev/ttyACM0`（CDC 虚拟串口）与达妙 `DM-USB2FDCAN` 模块收发 CAN 帧，验证「USB2CAN 替代 CANET」链路可行性。**不碰主工程任何代码**。

## 编译

```bash
cd tool/usb2can_probe
cmake -B build && cmake --build build -j$(nproc)
```

产物 `build/usb2can_probe`。

## 运行

```bash
sudo ./build/usb2can_probe /dev/ttyACM0 0
```

- 第 2 个参数：初始 CAN 波特率索引（`0`=1000k，`3`=500k，见下表）
- 用户需在 `dialout` 组（`groups` 查看），或对 `/dev/ttyACM0` 设 0666 权限

波特率索引：`0=1000k 1=800k 2=666k 3=500k 4=400k 5=250k 6=200k 7=125k 8=100k 9=80k 10=50k 11=40k 12=20k 13=10k 14=5k`

## 交互命令

| 命令 | 作用 |
|---|---|
| `b <idx>` | 设 CAN 波特率（如 `b 3` = 500k） |
| `h` | 发心跳（验证协议是否吻合，期望收到 `HEARTBEAT` 上报） |
| `r <id_hex>` | 发「读控制模式 0x5B」**只读**参数帧到电机 CAN ID（1~F），不动电机 |
| `c <id_hex> <d0..d7>` | 发自定义标准 CAN 数据帧（⚠ 若为控制命令电机可能动作） |
| `q` | 退出 |

## 测试步骤

1. **接线**：达妙模块 `CAN_H`/`CAN_L` ↔ 电机总线 `H`/`L`（高对高、低对低）。测试一路即可（如 CAN2 那路 4 个电机）。
2. **终端电阻**：总线末端需 120Ω（电机侧若已开 120Ω 则 OK）。
3. **波特率匹配**：先 `b 0`(1M) 或 `b 3`(500k)，**必须与电机总线现有波特率一致**（CANET 设备预设值），否则无通信。
4. **验证链路**：
   - `h` 心跳 → 期望收到 `[HEARTBEAT]`（协议吻合）；
   - `r 2` 读电机 2 控制模式 → 期望收到 `[TX_OK]`（发送成功）+ 电机回报（`RX_CAN`，或读参数回报）；
   - 观察回报帧的 CAN ID 是否为 `50+电机ID`（51~54）。

## 输出判读

- `[TX_OK] id=0x02 ...`：CAN 帧已发到总线（达妙模块反馈发送成功）
- `[RX_CAN] id=0x33 ...`：收到总线上的 CAN 帧（电机回报或他人发的）
- `[HEARTBEAT]`：模块协议应答正常
- 无任何输出：先查波特率是否匹配、接线是否正确、120Ω 是否就绪

## 安全提示

- `r`（读参数）安全只读；`c` 发自定义帧前确认是只读/诊断帧，否则电机可能动作。
- 建议测试时**电机不使能**，仅验证 CAN 链路收发。
